# Executive Summary

JamOn is a personalized music recommendation engine that generates event-specific Spotify playlists by combining retrieval-augmented generation (RAG) with large language models. The system analyzes each participant's personal listening library together with a natural-language description of an event to produce a playlist tailored to the occasion and the group's combined taste.

The system's core technical innovation is a descriptive-tagging pipeline that translates each song into rich natural-language text rather than a fixed set of numeric values. For each song, an LLM estimates energy, valence, and descriptive vibe tags from lyrics, artist genres, and community tags. These tags are combined with lyric snippets and embedded as vectors, allowing songs to be indexed and retrieved through semantic similarity. At inference time, a short event description is expanded through Hypothetical Document Embeddings (HyDE) into a synthetic song description, bridging the gap between a vague user query and the richer embedding space of indexed songs. Retrieved candidates are then passed to an LLM acting as a DJ within a LangGraph agentic workflow, which generates, validates, and retries playlist suggestions before resolving them to Spotify tracks.

The system was validated using a two-phase evaluation harness combining a parameter grid search with iterative prompt hill-climbing, judged in part by a NIM Llama-70b model. The best configuration achieved a training composite score of 0.80 and a holdout composite score of 0.69 on unseen event descriptions, confirming that the retrieval and generation pipeline generalizes beyond the events used for tuning. The system further supports multiple interchangeable LLM providers, balancing tagging, retrieval, and generation costs across deployment contexts.
